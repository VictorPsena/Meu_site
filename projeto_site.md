# Projeto do site

## Objetivo

Criar um site pessoal simples para reunir materiais de disciplinas e projetos, permitindo que colegas encontrem e baixem os arquivos disponibilizados.

## Aparência

- Fundo escuro, fonte monoespaçada e detalhes discretos inspirados em programação e matemática.
- Uma janela principal com navegação clara para **Disciplinas** e **Projetos**.
- Layout minimalista, adaptado para computadores e celulares.
- Uma única animação discreta de caracteres de código, sem atrapalhar a leitura. A animação respeitará a preferência do dispositivo por movimento reduzido.
- Textos curtos e funcionais, usados apenas para identificar seções, itens e ações. Não serão inventados nomes de disciplinas, projetos ou descrições.

## Organização e funcionamento

- **Disciplinas:** cada disciplina poderá reunir vídeos, listas e outros materiais, com links identificados para abrir ou baixar os arquivos.
- **Projetos:** espaço para listar projetos, com seus nomes e links para arquivos ou páginas relacionados.
- Mais seções serão feitas posteriormente
- Enquanto não houver conteúdo cadastrado, cada seção mostrará apenas uma indicação curta de que está vazia.
- O site será público quando publicado: qualquer pessoa com acesso ao endereço poderá acessar os materiais incluídos.

## Arquivos previstos

```text
meu_site/
├── index.html          # Estrutura e conteúdo do site
├── style.css           # Aparência e adaptação a diferentes telas
├── script.js           # Animação e interações necessárias
├── arquivos/           # Materiais organizados por disciplina
├── projetos/           # Arquivos de projetos, quando necessário
└── projeto_site.md     # Esta proposta
```

A inclusão de disciplinas, projetos e links será feita editando o HTML e adicionando os arquivos às pastas correspondentes. Vou deixar instruções curtas no projeto para facilitar essas alterações. Links relativos permitirão que o site funcione tanto localmente quanto no GitHub Pages.

## Publicação e arquivos grandes

O site será estático, sem servidor, cadastro ou instalação de dependências. Ficará preparado para publicação no GitHub Pages; a publicação dependerá de conectar a conta e criar ou configurar o repositório no GitHub. Não farei login nem publicação nesta etapa.

Arquivos pequenos poderão ficar no próprio repositório. Vídeos e outros arquivos grandes podem esbarrar nos limites de tamanho e uso do GitHub; nesses casos, será possível usar links para um serviço externo de armazenamento, configurado para permitir o acesso dos colegas.

## Verificação após aprovação

Vou conferir a navegação, a visualização em telas pequenas, os links de exemplo, a acessibilidade básica e o funcionamento do site como página estática. O conteúdo real será adicionado conforme você disponibilizar os nomes e arquivos.
